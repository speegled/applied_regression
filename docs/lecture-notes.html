9.1 January 27

Here is a summary of things to know from January 27.

  1. The function lm creates a model of the data using only those rows which aren’t missing any values. This only applies to variables that are listed in the formula as the first argument of lm.

  2. The formula for AIC is -2 log(likelhood) + 2k, where k is the number of parameters in the model. This means that AIC is explicitly balancing the fit of the model (the likelihood) with the number of parameters used. Lower values correspond to beter fits according to the AIC. AIC can only be used to compare two models that fit the exact same data.

  3. When using MASS::stepAIC, there can often be errors which come up because when a variable us removed, the data set changes. For example, if y ~ x1 + x2 is the original model, and x2 is removed, and there is missing data in the variable x2, then when lm is run on y ~ x1, we are using a different data set. This causes an error in MASS::stepAIC.

  4. We discussed several options for dealing with this.

    1. Remove all rows from the data that contain any missing values before running stepAIC.

    2. Every time stepAIC throws an error, remove that variable by hand from the original model and restart stepAIC from the beginning.

    3. Remove variables from the model (if they have two many missing values).

    4. Impute missing values. (We will learn how to do this later.)

  5. We also discussed multiple \(R^2\) and adjusted \(R^2\). Let’s see how those values are computed. Multiple \(R^2\) is computed as \[ (\mathrm{var}(y) - \mathrm(var)(\eps))/\mathrm{var}(y) \] while adjusted \(R^2\) is computed the same, except we use the unbiased estimator for the variance of the residuals. Let’s look at an example:

set.seed(1)
x1 <- runif(30)
x2 <- runif(30)
y <- 1  + 2 * x1 + 3 * x2 + rnorm(30, 0, 1)
mod <- lm(y ~ x1 + x2)
summary(mod)

(var(y) - var(resid(mod)))/var(y)

(var(y) - sigma(mod)^2)/var(y)

The point is that our unbiased estimator for \(\sigma^2\) in the model depends on the number of parameters and is larger if we have more parameters. This means that, like AIC, the adjusted \(R^2\) is evaluating a trade-off between model fit and number of parameters.

Note: \(R^2\) is always between 0 and 1, while the adjusted \(R^2\) can be negative.

9.2 February 3

Here is a summary of things to know from February 3. The main goals were to understand interactions and multicollinearity of the predictors.

There are three types of interactions that we are going to be thinking about in this class. We will provide examples of each type of interaction in the context of exam scores as described by various predictors.

factor vs factor interaction Two factors interact when the effect of changing levels in one of the factors depends on which level the other factor has. As a made up example, suppose students are randomly assigned to study flashcards or to do practice problems in preparation for an exam. numeric vs numeric In this case, the effect of changing a numerical predictor by one unit (the slope) depends on the exact value of a different numeric variable. The model for this is \[ y ~ \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x1 x_2 + \epsilon \] So that the change in slope of \(x_1\) depends in a very specific way on the value of the interaction variable \(x_2\). Let’s look at each of the new variables.

  • .fitted are the fitted values from the model.

9.3.2 Multicollinearity

Multicollinearity occurs when two or more predictor variables are highly correlated with each other. This can cause problems in regression models, because it can make it difficult to determine the individual effect of each predictor on the response variable. It generally does not negatively affect the overall predictive power of the model, but it can make the coefficients unstable and difficult to interpret.

To detect multicollinearity, we can use the Variance Inflation Factor (VIF). A VIF value greater than 5 or 10 is often considered indicative of multicollinearity. Variance Inflation Factor can be computed using the car package in R.car::vif computes the variance inflation factor by regressing each predictor on all the other predictors and computing the \(R^2\) value for that regression. The VIF is then computed as \[ VIF_j = \frac{1}{1 - R_j^2} \]

What should you do if you discover multicollinearity in your data? Here are some options:

  1. Do nothing. If your goal is prediction only, then multicollinearity may not be a problem. If interpretation is still your goal, you can try to interpret the highly correlated variables jointly, rather than individually.
  2. Remove one or more of the correlated predictors from the model. Often you will choose to keep the variable that is either cheaper to measure, more fundamental theoretically, or more interpretable.
  3. Combine the correlated predictors into a single predictor (e.g., by taking their average or sum). This is often used when you have domain knowledge of the predictors. For example, height and weight could be combined into a body mass index (BMI) variable. Or section scores of the ACT could be combined into a total score.
  4. Use regularization techniques (e.g., ridge regression or lasso) that can handle multicollinearity. (We have not yet covered this material.)

As a summary, multicollinearity does not break your model. It is not an assumption of OLS that the predictors are uncorrelated. However, it can make interpretation of the coefficients difficult, and can lead to large standard errors for the coefficients.

9.4.1 ANOVA Models2

ANOVA (Analysis of Variance) models are a special case of linear regression models where the predictors are categorical variables (factors). They are used to compare the means of different groups and to determine if there are significant differences between them. We have already studied linear models which contain only categorical data, so this is a review of that material with some additional nuances.

We begin with a brief review of one-way ANOVA models, which contain a single categorical predictor. The model can be written as \[ y_{ij} = \mu + \alpha_i + \epsilon_{ij} \] where \(y_{ij}\) is the response variable for the \(j\)th observation in group \(i\), \(\mu\) is the overall mean, \(\alpha_i\) is the effect of group \(i\), and \(\epsilon_{ij}\) is the random error term. The null hypothesis is that all group means are equal, i.e., \(\alpha_1 = \alpha_2 = \ldots = \alpha_k = 0\). This way of writing the model is called the effects coding. Another way to write the model is the treatment coding, which is more common in R, and is given by \[ y_{ij} = \beta_0 + \beta_i D_i + \epsilon_{ij} \] where \(D_i\) is a dummy variable that is 1 if the observation is in group \(i\) and 0 otherwise. In this case, \(\beta_0\) is the mean of the reference group (usually the first group), and \(\beta_i\) is the difference between the mean of group \(i\) and the mean of the reference group.

We assume that the errors are normally distributed with mean 0 and constant variance. The ANOVA table partitions the total variability in the data into variability between groups and variability within groups. The F-statistic is used to test the null hypothesis, and is computed as the ratio of the mean square between groups to the mean square within groups.

The model that we will use is3

\[\begin{equation} \text{RT}_{ij} = \gamma_{00} + \beta_1 \text{Voice}_{ij} + u_{0i} + \epsilon_{ij} \tag{9.1} \end{equation}\]

where:

  • \(\text{RT}_{ij}\) is the reaction time for participant \(i\) on observation \(j\)
  • \(\gamma_{00}\) is the mean RT when rating self voice (the reference category)
  • \(\beta_1\) is the difference in mean RT between rating other voices and self voice
  • \(u_{0i} \sim N(0, \tau^2)\) represents between-participant variance
  • \(\epsilon_{ij} \sim N(0, \sigma^2)\) represents within-participant variance
  • \(u_{0i}\) and \(\epsilon_{ij}\) are assumed to be independent

Interpretation: Each person’s reaction time is a function of:

  1. The mean RT for self voice (\(\gamma_{00}\))
  2. The difference in RT between other and self voice (\(\beta_1\)), which is constant across all participants
  3. That person’s individual baseline deviation (\(u_{0i}\)), which varies randomly across participants
  4. Random measurement error (\(\epsilon_{ij}\))

The key feature of this model is that it allows each participant to have their own baseline reaction time (random intercept) while estimating a common effect of voice type across all participants.

This would be fine if we were only interested in these subjects. More likely, though, we are imagining the subjects to be a random sample from a larger population, and we want to treat the intercept as a random effect and the slope as a fixed effect. This way, we can make inferences about the overall effect of days of sleep deprivation on reaction time, while accounting for the fact that each subject has their own baseline reaction time (random intercept). The model would be \[ \text{reaction}_{ij} = \gamma_{00} + \beta_1 \text{days}_{ij} + u_{0i} + \epsilon_{ij} \] where

-\(\gamma_{00}\) is the mean reaction time for a subject with 0 days of sleep deprivation, -\(\beta_1\) is the fixed effect of days of sleep deprivation on reaction time -\(u_{0i} \sim N(0, \tau^2)\) represents the random intercept for subject \(i\) -\(\epsilon_{ij} \sim N(0, \sigma^2)\) represents the error term for observation \(j\) of subject \(i\) -\(\tau\) and \(\sigma\) are the variances of the random intercepts and the error term, respectively. -We assume independence between the random intercepts and the error term, and we also assume that the random intercepts are independent across subjects.

9.7.1 Random Slopes

When we have one predictor with random intercepts and slopes, the model can be written like this:

\[ y_{ij} = \beta_0 + \beta_1 x_{ij} + b_{0i} + b_{1i} x_{ij} + \epsilon_{ij} \] where \(b_{0i}\) is the random intercept for group \(i\), and \(b_{1i}\) is the random slope for predictor \(x\) in group \(i\). We assume that the random effects \((b_{0i}, b_{1i})\) are jointly normally distributed with mean 0 and covariance matrix \(\Sigma\), and that the errors \(\epsilon_{ij}\) are normally distributed with mean 0 and variance \(\sigma^2\). The random effects and errors are assumed to be independent of each other. Note that we could also combine the fixed effects with the random effects to say that the intercept has mean \(\beta_0\) and the slope has mean \(\beta_1\), together with the covariance informarion.

9.7.2 Comparing models

We can use ANOVA to compare nested models. For example, we can compare the model with random slopes to the model without random slopes, or we can compare the model with random slopes and random intercepts to the model with only random intercepts. We can also compare the model with correlated random effects to the model with uncorrelated random effects. Let’s see how to do this in R.

mod_random_slopes <- lmer(reaction ~ days + (1 + days|subject), data = ss)
mod_random_intercepts <- lmer(reaction ~ days + (1|subject), data = ss)
anova(mod_random_intercepts, mod_random_slopes)

In general, the null hypothesis being tested is that all of the extra parameters in the larger model are zero versus at least one of the parameters is not zero. So, a \(p\)-value less than 0.05 is evidence that the larger model is a significantly better fit to the data than the smaller model, which suggests that at least one of the extra parameters in the larger model is not zero. In this case, we are testing whether the variance of the random slopes is zero, which is equivalent to testing whether the random slopes are necessary to explain the variability in the data. If we reject the null hypothesis, we can conclude that there is significant variability in the slopes across subjects, and that the model with random slopes fits significantly better than the model with only random intercepts. If we fail to reject the null hypothesis, we can conclude that there is not enough evidence to suggest that there is significant variability in the slopes across subjects, and that the model with only random intercepts may be sufficient to explain the variability in the data. We can also look at the AIC or BIC values for the two models, which are measures of model fit that penalize for the number of parameters in the model. The model with the lower AIC or BIC value is generally considered to be the better fitting model. In this case, we would expect the model with random slopes to have a lower AIC and BIC value than the model with only random intercepts, which would further support the conclusion that the model with random slopes fits significantly better than the model with only random intercepts.

We conclude that the model with random slopes fits significantly better than the model with only random intercepts, which suggests that there is significant variability in the slopes across subjects. This estimate gives us a variance of nearly 12, which is quite large. The estimate from lmer is zero, which suggests that we don’t have enough data to properly estimate the variance of the random intercepts. This is a common issue when we have a small number of groups (in this case, conductors) and a small number of observations per group. In this case, we have 36 conductors and five observations per conductor for mark 84, which is not a lot of data to estimate the variance of the random intercepts. This is why we get a zero estimate for the variance of the random intercepts, which is likely not the true value, but rather an artifact of the limited data we have for this particular mark.
